# Guías de uso

Para las empresas que usan NX Time. Se pueden mandar tal cual, o exportarlas a
PDF, al aprobar el alta de una empresa.

| Guía | Para quién |
|---|---|
| [Puesta en marcha](puesta-en-marcha.md) | Quien administra la empresa (ADMIN) y RRHH: lo que hay que hacer la primera semana |
| [Fichar y el día a día](fichar.md) | Toda la plantilla |
| [Gestores y RRHH](gestion.md) | Quien aprueba ausencias y correcciones y revisa los fichajes del equipo |
| [Soporte](soporte.md) | Todos: qué hacer cuando algo falla y a quién escribir |

Los textos legales (cláusula para la plantilla, información sobre la ubicación)
están en [`docs/cumplimiento/plantillas-para-clientes.md`](../cumplimiento/plantillas-para-clientes.md).

> **Antes de mandarlas**: rellenar lo que va entre corchetes en
> [soporte.md](soporte.md) (el correo de soporte y el plazo de respuesta), y
> cambiar el nombre y la dirección web si el producto ya se ha renombrado.
